# 改名リネームの before/after 一致確認（2026-09-05）

対象: `sim/seishu_sim.py` の文言・識別子のみの改名（火落ちの読み替え／`Rarity.JUNMAI`→`HONJOZO`／きょうかい6号→14号）。
**数値・テーブル・確率・閾値は一切変更していない。**

## 乱数の固定方法

`main()` 冒頭の `rng = random.Random(20260719)` が唯一の乱数源で、全実験がこの1本を順に消費する（seed引数なし・環境依存なし）。
改名は乱数の消費順・消費回数を変えないため、同一seedなら数値は完全一致するはず、という検証。

## 実行コマンド

```
python3 sim/seishu_sim.py          # 改名前
python3 sim/seishu_sim.py          # 改名後
diff -w <(改名前を YEAST_A / RA1 に正規化) <(改名後を YEAST_A / RA1 に正規化)
```

正規化＝改名した表示名だけを共通トークンに置換（`きょうかい6号`／`きょうかい14号` → `YEAST_A`、`JUNMAI`／`HONJOZO` → `RA1`）。

## 結果

**一致（勝率・平均tick・平均発酵回数の全数値が完全一致）。**
生の diff に出た差分は2行のみで、いずれも `f"{yeast.name:<10}"` の桁揃えが酵母名1文字増で1スペース詰まったもの。数値そのものの差ではない（`diff -w` で差分ゼロ）。

```
5c5
< YEAST_A   100.0%  72.1t 36.7発  ...
> YEAST_A  100.0%  72.1t 36.7発  ...
11c11
< YEAST_A     0.0%  57.0t  6.0発  ...
> YEAST_A    0.0%  57.0t  6.0発  ...
```

`diff -w`（空白無視）の結果: 差分なし。
