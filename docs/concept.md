# 清酒無双 構想メモ（2026-07-19 正式化。旧プロトタイプ名: もろみ無双）

日本酒の醸造ロジックをハクスラ無双に昇華する。この文書が用語対応の正。

## 用語対応表

| 醸造 | ゲームシステム |
|---|---|
| 並行複発酵 | コア戦闘ループ。通常攻撃（櫂入れ）で「糖化（ブドウ糖）」を稼ぎ、消費して「発酵（アルコール必殺技）」を放つ |
| 精米歩合 | 武器強化。%を下げるほど攻撃力倍率が上がる（70→50→35、35未満なし） |
| 上槽 | クリア報酬。醪を搾って防具（酒米）がドロップするハクスラ判定 |
| 酒米（山田錦・五百万石…） | 防具。固定メインスキル＋ランダムサブスキル |
| 精米歩合（普通酒/本醸造/吟醸/大吟醸） | レア度。**精米歩合の一軸**（本醸造70%以下・吟醸60%以下・大吟醸50%以下。日本酒の基 3.表示 p.9）。大吟醸=サブスキル4枠確定。原料軸（純米）はここに混ぜない |
| 仕込み方（純米／本醸造系） | 酒米（防具）の切替項目。**原料軸**でレア度（精米歩合の一軸）と直交する。両方に利と害を置き格は横並び。蔵に入る時点で固定（2026-09-06決定。下の「仕込み方」節が正） |
| 酵母（きょうかい14号/7号/9号） | ブドウ糖を消費する固有チャージ技 |
| 麹（黄/白/黒） | 武器に塗る属性。並列の個性であり相性関係は持たせない。入手＝火落ち菌の戦利品（2026-07-19決定） |
| 火落ち菌 | 呂布枠。**醪を搾った瞬間、できた酒に火落ち菌が湧く。殺菌（火入れ）するまで蔵は制圧できない**（火落ちは上槽後の清酒で起こる腐敗現象。酒造講本 p.16）。乱入中はゲージが減り続ける |
| 酒蔵（Kura） | 拠点。初版は広大マップにせず1タンク=1蔵の連戦で進軍感を出す |

## 数値確定候補（2026-07-19 sim/seishu_sim.py 実測・各1000回ロール）

- **糖チャージ率＝与ダメの2%**。原案の10%は毎ターン必殺が撃てて崩壊（1戦26発）。2%で1戦3〜5発の「必殺」感になる
- **酵母3種の役割分担**（三すくみなしでも並ぶ）:
  - きょうかい14号（金沢酵母）＝コスト80・全体3秒凍結 → 勝率99.8%・平均55.8t（最遅だが最安全。生存特化）。低温でも発酵力が強い（日本酒の基 p.32）＝凍結・生存特化の写像
  - きょうかい7号＝コスト100・全体600%（原案500%から増） → 勝率97.2%・平均38.7t（殲滅速度特化・唯一事故る）
  - きょうかい9号＝コスト100・単体500%防御無視+2秒スタン（原案1000%から半減） → 勝率100%・平均38.2t（対ボス安定。強さの正体は倍率ではなくスタン）
- **精米歩合の式は原案どおり**: 70/50/35% → 攻撃力100/140/170。精米50→35は勝率0→100%を分ける支配的な強化で、成長の柱として機能する
- **上槽レア度テーブルは原案どおり**（NIGHTMARE=大吟醸100%を含め分布に問題なし）
- **再設計結果（2026-07-19 おまかせ分。旧案の罠3点を修正済み）**:
  - クリティカル軸を土台から底上げ: クリダメ倍率150%→**200%**。これで山田錦（クリ率+25%）が五百万石と同格に並んだ（大吟醸同士で33.9t vs 32.5t・勝率100%同士）
  - 黄麹: 旧クリダメ+20%（実質+7%で最弱）→ **クリ率+15%** に変更。山田錦と組むとクリ率50%のクリビルドが成立
  - 箱麹: 効果はそのまま攻撃範囲1.5倍とし、**手触り層では範囲＝ヒット数＝糖化効率として自然に強い**（JS実装は既にヒット数でゲージが溜まる）。simでは糖+35%相当で近似
  - 再設計後の麹3×仕込み2×米2の全組み合わせが勝率89.5〜100%・36〜42tの帯に収束。一択も罠もなし
- **simは2026-07-19をもって凍結**（初期バランス確定の役目を完了。以後は実機の体感で調整し、大改修時のみ復活させる）
- モデルの前提と限界: 1tick=1秒・回避50%でアクション層を近似した比較用の土俵。絶対値でなく差を読む。**敵火力x4基準は生死の境界（ナイフエッジ）にあり、勝率は±数%の変化で20pt動くことがある。細かい優劣はクリア時間で読み、範囲系の価値はアクション層で検証する**

## 純米の扱い（検討案・未採用）

**→ 2026-09-06 採用案は下の「仕込み方（純米／本醸造系）」の節。以下は当時の検討記録として残す。**

レア度は精米歩合の一軸に確定したので、原料軸（醸造アルコール不使用＝純米）をどう乗せるかは別問題として残る。特定名称は原料軸×精米歩合軸の直交2軸で、純米大吟醸が成立する（日本酒の基 3.表示 p.9）。以下は叩き台。

- **案A: 別バッジとしてドロップ時に付与**
  レア度と独立に一定確率で「純米」フラグが立ち、名前が「純米大吟醸・山田錦の魂」になる。純米ならサブスキル1枠追加など小さな恩恵を1つだけ持たせる。2軸の事実に最も忠実だが、ドロップ判定と装備表示が2軸に増える。
- **案B: サブスキルの1種として持つ**
  「純米仕込み」をSUB_SKILLSの5種目に足し、既存の枠数の中で引く。実装は1エントリの追加で済み、レア度テーブルも装備画面も無改造。ただし「純米＝スキルの一つ」になるので特定名称としての意味は薄れる。
- **案C: 上槽後の演出のみ（足さない案・推奨）**
  ゲームシステムには乗せず、上槽カットインの文字や蔵の説明でだけ「純米仕込み」を語る。数値もUIも増えず、間違った一直線（普通酒<純米<吟醸）を復活させる危険もない。**初版はこれで足り、必要になってから案Aへ広げられる。**

## 仕込み方（純米／本醸造系）2026-09-06 採用

酒米（防具）に「仕込み方」の項目を付け、純米／本醸造系を切り替えられるようにする。原料軸であり、レア度（精米歩合の一軸）とは**直交する別軸**。特定名称は2軸で決まるので、純米大吟醸が成立する。

**事実の土台**: 純米＝米・米こうじ・水だけで造る。本醸造系＝醸造アルコールを白米重量の10%以下で添加する（清酒の製法品質表示基準・国税庁告示第8号）。アル添は「増量」ではなく香味の設計手段で、粕歩合も下がる。

### 効果（数値は sim 実測後の値。`docs/sim_style_check.md` が実測の正）

| | 純米 | 本醸造系 |
|---|---|---|
| メリット | 被ダメージ **-5%**（コク＝厚みの写像）／上槽の名前に「純米」が付く | 上槽ドロップ数 **+1**（アル添で粕歩合が下がる写像）／香り演出＋（数値化しない） |
| デメリット | 糖化（ブドウ糖蓄積）**-10%** | 純度🍶の上限 **-1**（淡麗＝厚みが減る写像）／名前に「純米」が付かない |

被ダメは叩き台の-10%から-5%へ1つだけ動かした（-10%では9号×精米70%×糖2%で勝率差7.0ptが出て横並びが崩れたため。理由の全文は `docs/sim_style_check.md`）。

### 勘所

1. **どちらも格は同じ**（横並び）。普通酒<純米<吟醸のような一直線を復活させない
2. **切替は蔵に入る時点で固定**（sim では `Rice.style` として固定。戦闘中に切り替えられない）
3. **効果は各側1〜2個まで**。足さない

### 名前の合成規則

| 仕込み方 | 普通酒 | 本醸造(70%以下) | 吟醸(60%以下) | 大吟醸(50%以下) |
|---|---|---|---|---|
| 純米 | 無印（「純米」を付けない） | 特別純米 | 純米吟醸 | 純米大吟醸 |
| 本醸造系 | 無印 | 本醸造 | 吟醸 | 大吟醸 |

純米は精米歩合の規定を持たないため、普通酒段階には「純米」を付けない（付けると精米歩合の階段と混ざる）。
